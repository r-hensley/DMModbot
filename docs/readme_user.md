# DMModbot user guide

Use DMModbot to send a private report or question to your Discord server’s staff.

## Start a report

1. Open a DM with the bot and send a message or use `/report` to open the report form. You can also use `/report` or the report button in your server, if available, and follow the prompt to your DMs.
2. Press the start button in the bot’s reply. Choose from the shared servers that accept reports, then select a topic. If only one server is available, it is selected automatically. Using `/report` again keeps your current draft.
3. Describe what happened. Include relevant usernames, message links, screenshots, or other evidence. You can add details and attachments by sending them in the DM. Use **$edit** to change the text before sending.
4. Select **$send** and wait for **$sent** or **$sent_anon**. **$cancel** discards the draft if you change your mind.

The topic menu can include:

$topic_list

For voice access, follow the form’s prompts and choose **$send_request** when that option appears. Staff can see your account for a voice access request.

## Send anonymously

Turn on **$anonymous** before sending. The bot hides your Discord account from staff in the ticket, but details you share, including screenshots and links, can identify you. Review your draft and attachments before submitting.

## Follow up or close the report

After the report opens, send follow-ups and attachments in the same DM. Staff replies appear there. Keep the conversation open while you wait for a reply.

When you’re done, choose **$close** and confirm, or send `end` or `close` as a message. To start another report after closure, send a new DM to the bot.

## If you need help

- If the bot can’t DM you, check your Discord privacy settings for the server, then try again.
- If the server is missing from the menu, contact its moderators directly. Regular DM reports require a shared server with reporting set up.
- For a ban appeal, use the server’s designated appeal process. If it has a DMModbot appeal server, follow the instructions there and use its ban appeal button.
